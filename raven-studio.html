About this adaptation & how to use it

Download this HTML file and open it directly in a modern browser. Everything runs on your device: no installation, server, network connection, external fonts, or libraries are needed. Use New puzzle for a fresh seed, or Load to reproduce a puzzle with its seed and settings. Changing a setting starts a new puzzle with the displayed seed.

This is a JavaScript/SVG adaptation of cmekik/pyRavenMatrices, inspected at commit 0dd8b0376a4d054e9ab65edf604f5c004aae9dd1. The six original shape geometries and modifier behavior are adapted from lib/sandia/definitions.py; the figure model follows element.py. This page adds circle, square, cross, kite, hexagon, and star figures for the advanced outline and transformation puzzles. Cairo drawing is replaced by inline SVG. The original repository generates figures and provides matrix/transform structures; the complete puzzle rules, seeded generator, distractors, scoring, explanations, and interface are additions in this file. It does not execute Python or reproduce the original random sampler.

The Combine several transformations lets you tick one transformation or any combination. The A↔B outline transposition is an optional outer layer: it can appear beside a normal central figure undergoing rotation, translation, rototranslation, scale, and/or mirroring; it does not force every matrix to use an outline. Dense A↔B transposition samples a complete perimeter at evenly spaced intervals, so the outline is a string of repeated small figures rather than isolated corner markers. Its horizontal rule is strict: a set of A shapes traces the perimeter of B, then a set of B shapes traces the perimeter of A; applying the same transposition once more returns to A-on-B. The focused outline and Boolean drills retain XOR, OR, AND, subtraction, and true multiset SUM; in SUM, a shared perimeter group visibly contains two nested copies. Their opaque grey cover moves and turns by a regular rule, and it is drawn deliberately large enough to visibly hide the item underneath; shape-specific sizing is used so even broad covers such as the T-shaped one properly hide the symbol below, letting the hidden active item be inferred from the row and column logic. Black, white, grey, and monochrome-pattern fills are the only shape distinctions. Complexity is not a standardized difficulty or IQ score. Hinted checks count toward accuracy and are also recorded as assisted. Showing a solution is recorded separately and does not count as a checked answer. The original repository has no license file; original authorship is retained here without asserting a redistribution license.

Keyboard: 1–8 select an answer; Enter checks it; N starts a new puzzle when you are not editing a field. The Figure lab lets you explore the original shape vocabulary independently of the puzzle generator.
