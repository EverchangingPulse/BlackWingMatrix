# Response-time calibration

BlackWingMatrix uses response time as bounded supporting evidence for its existing adaptive test. It does not turn response time into an IQ score or replace correctness, the progressive flow, answer-distance evidence, or the calibrated 1–60 difficulty scale.

![Response-time signal](time-calibration-curve.svg)

The PNG counterpart is [time-calibration-curve.png](time-calibration-curve.png), generated by [generate_time_calibration_plot.py](generate_time_calibration_plot.py). The script reads the embedded runtime payload, so the chart cannot silently document an obsolete curve.

## Runtime model

Each item has an expected time derived from its family and item score:

$$
E(f,s)=\operatorname{clamp}_{[12,150]}\left(13+0.65s+o_f+o_{\mathrm{ternary}}+9c\right).
$$

`o_f` is the report-calibrated family offset, `o_ternary` is determined by the rendered 2×2, 3×3 or 4×4 ternary grid, and `c` is any available answer-space crowding signal. The initial values preserve the active `dev` timing settings and the prior family-specific improvements.

The response-time signal is logistic and is centred on this contextual expectation:

$$
S(t)=1-2\sigma\left(\frac{t-E(f,s)}{w}\right),
\qquad
w=\max(8,\min(w_{\max},0.38E(f,s))).
$$

Fast correct responses may raise the next target slightly; slow responses reduce that uplift. Incorrect answers retain their normal error treatment, while very rapid errors are deliberately down-weighted. The gradual mode, its calibration items, recovery safeguards, high-water floor and post-calibration caps remain independent controls and are not overwritten by report imports.

## Updating from reports

Use CSV or JSON exported by the adaptive test:

```bash
python3 tools/recalibrate_reports.py report-a.csv report-b.json
```

The tool accepts `family`, `itemScore` (or `targetDifficulty`) and a duration in seconds or milliseconds. It ignores records excluded from evaluation and `ignored-too-fast` responses. Ternary rows may additionally include `ternaryGridSize`; that prevents the larger ternary panels from being treated as a generic family slowdown.

Each report is tracked by SHA-256, observations are deterministically limited to 500 per family, and the script updates both `index.html` and `blackwingmatrix.html` from one generated payload. It writes `tools/last-recalibration-summary.json` after a non-dry run.

- `--dry-run` calculates the merged result without modifying files.
- `--replace-observations` discards prior embedded observations; use it only for a complete replacement dataset.
- `--reestimate-curve` additionally refits the context-free fallback neutral time and the sigmoid-width cap. By default those current parameters are preserved.

The recalibration tool never changes the adaptive-family pools, gradual-test safeguards, explanation text, or generator rules. It only replaces the explicitly marked response-time payload.

## Limitations

This is a product calibration aid, not a validated psychometric norm. Any published comparative or diagnostic claim needs a preregistered study with sufficient representative data and an appropriate joint speed–accuracy model.
